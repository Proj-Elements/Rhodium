# 前端重设计记录

本文件保留重设计阶段的历史说明。当前 Rhodium 的报销、并发编辑、历史记录、失败重试与最终验证结果见 [2026-11-11 全面审查记录](review-fixes-2026-11-11.md)；历史端口、分支与测试数量不代表当前状态。

## 设计与范围

- 方向：暖白纸感、深松绿、留白与清晰的财务数字层级；亮色和暗色使用同一套语义 token。
- 重设计财务总览、收支明细、固定支出、月度回顾、设置，以及共用导航、记账表单、确认弹窗和错误页面。
- 保留现有 API 和账本模型，不包含登录、多人账本、真实扣款、发布或部署变更。
- 组件使用 HeroUI v3 与 HeroUI Pro；字体 DM Sans、Gravity UI 图标均本地提供，不依赖外部字体或图标请求。许可证保留在 `public/fonts/` 和 `public/icons/`。
- 图标数据可用 `node scripts/generate-icons.mjs` 从锁定的 `@iconify-json/gravity-ui` 重新生成。

用户提供的 [HeroUI Pro Figma Kit V3](https://www.figma.com/design/2ECV0W897UVwIqbJmNf32R/HeroUI-Pro-Figma-Kit-V3?node-id=23248-25843) 已通过 Figma MCP 尝试读取，但当前账号的 MCP 配额耗尽，未取得节点设计上下文或截图。本次实际依据为 HeroUI 官方 v3 文档、已安装 Pro 组件的类型/源码及两个 HeroUI 技能；不是对该 Figma 节点的逐像素还原。

## 行为修复

- 记账日期：同月尊重“上次使用”；历史/未来月份保持所选月份上下文；无效或不可用的 localStorage 不再中断记账。
- 固定支出：区分硬删除与保留历史后的暂停响应；月度金额不再计入未开始、已结束或分类停用的项目；下次记录日处理短月和闰年。
- 收支明细：包含历史账目的已停用分类仍可用于筛选。
- 分类占比：整个月只有零元支出时显示 0%，不会出现 `NaN%`；零元账目仍正常保留。
- 回顾日历：点击固定日期后不会因移开鼠标或失焦而丢失选中状态；切换月份重置选择。
- 表单：保存期间禁止重复提交和误关闭，失败时保留输入；危险操作提供确认和取消路径。
- 弹窗：由 HeroUI 管理焦点、背景隔离与恢复，小屏长表单支持内部滚动。
- 设置：导入成功后重新读取分类/预算，存储偏好失败时提供反馈。

日期偏好与固定支出删除回归均先重现失败，再通过新增测试验证修复。财务金额仍以分存储；现有业务允许零元记录，未擅自改变。

## 后续细节修正

- 移除桌面侧栏和移动导航内重复的主题切换，只保留右上角入口。
- 弹窗改用 HeroUI `Modal.Header / Body / Footer`，正文是唯一的滚动容器，标题和操作区保持可见。取消分类网格的嵌套滚动及默认单选项的额外外边距；去除横向溢出，小屏仍可以触摸、滚轮或键盘访问全部表单内容。
- 新分类类型和图标选择使用 HeroUI v3 `Select / ListBox`，不再使用原生类型下拉。提供 16 个离线图标及自动匹配，创建失败时保留选择，成功后恢复自动匹配。
- 分类增加可空 `icon` 字段，迁移仅新增列、不重写现有账目。图标经 API 白名单校验，传递到设置、记账、明细、总览及固定支出展示。
- JSON 备份保留自选图标；恢复时按分类自然键合并图标。旧备份没有该字段时保留当前选择，显式 `null` 恢复自动匹配。CSV 账目格式不变，完整分类元数据应使用 JSON 备份。
- Docker 构建上下文排除 `.next-*` 隔离预览产物，防止将测试构建混入正式源码构建。

本轮运行受影响的 4 个单元测试模块（86 项）和分类/账目契约集成测试（24 项），类型检查、受影响源文件 ESLint 和生产构建通过。分类后端的独立暂存快照也通过类型检查、77 项单元测试及 6 项分类图标集成测试，未包含任务开始前的其他改动。所有迁移和写入验证均只在隔离测试库执行，真实账本未迁移。

## Rhodium 命名与布局修正

- 产品改名为 Rhodium，同步页面标题、侧栏品牌、错误/回顾/固定支出文案、导出文件名和随应用分发的技能说明。数据库、数据卷、浏览器偏好键不改名，保持现有账目和设置兼容。
- favicon 使用松绿色圆角底和单笔 R 标记，提供 SVG 及 16/32/48px ICO；侧栏和 404 页沿用同一标记。
- 主题按钮保留单一入口，系统亮色时按「系统 → 暗色 → 亮色 → 系统」循环，系统暗色时按「系统 → 亮色 → 暗色 → 系统」循环，不再跳过亮色。提示同时标注当前模式与下一模式。
- 收支筛选栏缩减为 12px 纵向内边距，控件统一 40px 高，搜索框占用中间空隙。根据容器宽度保持桌面三列、窄屏两行、手机单列，不影响搜索和分类筛选。
- 移除主内容页脚及侧栏底部的文案/同步成功提示；账本设置移入侧栏底部，桌面与移动导航共用。后台订阅同步保留，仅失败时在内容区提示。

主题跳过亮色和导出旧名称均先由回归测试复现，再验证修正。受影响的主题、导出、CSV 和导入解析 4 个单元模块共 28 项通过；受影响源文件 ESLint、生产构建、图标 HTTP 响应通过。浏览器用现有合成数据预览库验收系统亮/暗三态循环、显式亮色刷新保留、搜索/分类/类型筛选、900/865px 换行和 360 × 640 单列无横向溢出；移动端账本设置位于抽屉底部，点击后正常关闭导航。浏览器没有捕获警告或错误。
