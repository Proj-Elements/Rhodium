# 代码质量修复验证记录

本文件保留早期修复的历史验证。当前 Rhodium 的账务、恢复、请求安全、容器与 main 分支清理结果见 [2026-11-11 全面审查记录](review-fixes-2026-11-11.md)，不以本文件中的旧测试数量代替当前结果。

初始基线：`9dec444`；前期工作树：`dsh/quality-hardening`。后续在 `codex/quality-hardening-finish` 整合 `main@2211fa4`，保留报销与撤销报销契约。原 dsh 工作树及其未提交 CI 草稿不变。测试只使用本任务创建、带 `rhodium:test-database` 标记的 PostgreSQL 临时库。没有迁移、清空或写入真实账本，没有执行生产部署。

## 已定位与修复

- JSON 备份遗漏默认预算；同名订阅按名称合并丢记录；历史分类归档状态丢失。新增 8 个真实 PostgreSQL 恢复回归，先失败再通过；旧备份无默认预算字段保留现值，显式 null 表示未设置。
- 客户端读取响应体时取消被吞掉；无效成功 JSON 被当作空对象。回归先失败，修复后请求模块 19 项通过。
- 数据库测试曾回退真实 DATABASE_URL。现在仅接受显式回环测试库、public schema，并在同一连接核对数据库/用户/schema/允许清空标记。
- 请求体原先读完才检查大小。现在按输入字节限制读取并取消超限流；跨块 UTF-8 保持正确。
- Zod 3 的 array.max 仍遍历所有元素、积累错误。超限集合在 preprocess 中立即终止；针对 501 个非法分类，错误数量从 502 条降至 1 条。此为项目可达路径缓解，不宣称修复依赖包本身。

## 收尾回归（2026-11-05）

- 所有 API 账本写入、订阅同步、预算与结算共享 PostgreSQL 事务级 advisory lock；检查和写入都使用持锁连接，失败整体回滚。`ReadCommitted` 确保等待后读取前一写入的已提交状态。该协议仅覆盖应用写入，不约束外部直接 SQL；单人账本以写吞吐换取一致性。
- 接入当前 main 的报销与撤销报销，不使用全局 Prisma 客户端绕过写锁。真实数据库测试覆盖写入先行、结算先行、编辑跨月、删除/恢复、报销/撤销、导入和预算，以及同步/暂停/删除竞争和失败重试。
- 新增并先复现四个遗漏：恢复丢失已释放 occurrence key 的软删除历史；合法的超过单笔金额上限的结算无法导入；已存在系统分类的排序未恢复；共享预算辅助函数可改写已结算月份。修复后均通过。
- JSON 导出使用一致性快照；默认预算区分零、未设置和旧备份字段缺失。导入仍是合并，不是清空替换；已结算目标须先重新打开。订阅按稳定 ID 区分，同名不是身份键。
- 文件预览拆成独立状态组件，持续显示读取中、校验错误和可导入状态；读取失败、旧请求和设置尚未加载时不可提交。新增组件渲染回归，不靠源码字符串断言。
- 收尾后 14 个相关单元模块 198 项、8 个受影响 PostgreSQL 模块 106 项和 9 项 CI 选择器测试通过；TypeScript、受影响文件 ESLint 和生产构建通过。这些是本地验证，不冒充远程 CI。
- 生产预览使用另一独立空库和 3032 端口。真实浏览器阻断预算/月度接口时显示持续错误、隐藏设置写入并禁用结算；解除阻断后重试恢复；390px 手机视口无横向溢出，快速切月后显示最终月份。请求阻断和视口覆盖已撤销；未操作真实账本。

## 依赖修补与构建链

- Zod 已单独迁移到 `4.6.7`，适配 record 双参数、集合问题 origin 和错误 flatten API，保留零预算、默认值、严格动作体和导入校验语义；不是 `npm audit fix --force`。
- Vitest/mocker 升至 `5.0.3`；仅对受影响的 minimatch 7–10 路径覆盖 `11.0.4`，旧 3.x 路径不变；figlet 固定 `1.11.3`，tar 固定 `7.5.21`。实际 lint、相关单元/集成测试和安装器帮助命令通过。
- `hpsetup@4.7.4` 加入开发依赖和锁文件；Docker、CI、本地初始化直接执行该锁定安装器，不再临时下载其传递依赖。CI 检查初始化前后清单/锁文件不变，并为 Docker 改动增加真实构建、非 root/无运行时密钥检查及健康启动/退出验证。
- `npm audit` 命令仍因 registry TLS 失败，不能记为通过。另用 curl 向官方 `registry.npmjs.org/-/npm/v1/security/advisories/bulk` 提交锁文件中的公开包名/版本：修补前返回 zod、figlet、minimatch、mocker，安装器锁定时另发现 tar；最终返回 `{}`。此结果是当时已知 advisory 匹配，不是完整供应链/应用安全证明。
