## Responsibility

共享逻辑提供 Rhodium 的计算语言与可复用行为：金钱/日期转换、DTO 类型、分类颜色/图标、预算解析、财务汇总、订阅计划历史与去抖、CSV/导入规范化、输入验证、序列化及数据库访问单例。

纯业务计算与其数据库协调显式分开：计划与汇总折叠可独立测试，而预算解析、月份锁读取及订阅同步用它访问持久化。API DTO 与浏览器类型共享私有枚举映射，不让数据库序列化格式直接替代产品契约。

## Boundary

- 可供 UI 和 API 复用的模块必须不引用 `lib/prisma.ts`、Node-only API 或服务器单例；不能以“共享”为由把 Prisma 间接送进客户端包。
- API 专属副作用可依赖 Prisma，但不得反向依赖 HTTP request、路由、React 组件或浏览器状态。
- 一份金额/日历实现是权威；新增代码不得在 UI、路由或导入器中另写不同的舍入、月份或短月规则。
- 字符串金额只接受明确的十进制格式和规范千分位，拒绝科学计数、十六进制与任意逗号拼接；金额范围及小数转换在公共入口统一处理。
- 自付汇总排除软删除和已报销支出；零预算保持已设置状态；已结算预算来自结算快照。
- 订阅计划根据生效月份与暂停日期决定是否产生账目；未知历史缺口可报告，不能按当前价格静默补齐。
- 订阅 DTO 的顶层金额、分类和起止月份反映最新保存计划，可能尚未生效。`currentAmountCents` 来自本月有效且在起止月份范围内的计划，无可用计划时为 `null`；`currentCategory` 按本月有效计划的分类身份单独加载。界面还须结合启用状态、分类状态和扣款日的订阅/分类暂停区间判断本月是否计入固定支出，下次日期按有效计划历史和暂停区间计算。
- CSV 的公式防护编码仅在最后一列 `__rhodium_csv_encoding`、各行值为 `apostrophe-v1` 时反解；普通 CSV 不猜测去除前导单引号。备份预检与导入共用完整校验，不能用宽松预览承诺随后无法恢复的数据。
- 默认分类通过进程标记和数据库自然键幂等补充；真实备份的恢复身份不能降级为不受控的任意 ID/对象透传。
- 跨域依赖与历史锁定/订阅/备份规则由 `rhodium-architecture` 统一记录；这里只拥有共享实现与可复用边界。
- 浏览器展示辅助与 CSV 可在客户端运行，但秘密、服务环境变量、数据库凭据和 Prisma 类型只属于服务端边界。
